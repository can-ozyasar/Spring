# Spring

Spring ekosistemiyle çalışma ve örnek Java uygulamaları için ayrılmış repo.

## Öne Çıkanlar
- Java/Spring öğrenme alanı
- Backend geliştirme pratikleri için başlangıç
- İleride modül ve örnek servis eklemeye uygun yapı
- Kullanılan ana teknolojiler: Java, Maven

## Kurulum
```bash
cd Ders12-Rest api ile Get isteği atma,Ders13-@PathVariable kullnanımı/spring-rest-api && mvn install
```

## Çalıştırma
```bash
cd Ders12-Rest api ile Get isteği atma,Ders13-@PathVariable kullnanımı/spring-rest-api && mvn spring-boot:run
```
